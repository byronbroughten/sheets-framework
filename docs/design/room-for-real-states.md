# Give the model room for the states that actually occur

Design reasoning. The one-line principle lives in [`docs/design.md`](../design.md); this file holds the argument and its instances.

## The argument

A state model that can't express a real condition doesn't omit it — it *misreports* it as one of the states it does have. Before settling a model, ask which real-world conditions have nowhere to go.

## Instances

A run killed mid-flight — an Apps Script timeout, a quota kill — runs no `finally`. Under the old boolean, it displayed the *previous* run's `TRUE`: a state with no representation became a confident lie. [ADR 0001](../adr/0001-carry-a-runs-outcome-in-a-cell-colour-nothing-reads-back.md) paints the run's cell yellow when it starts, so that run stays yellow, which says "started, never reported back". Every cell's value type includes `""`, because an untouched cell is empty rather than defaulted — a `boolean` column reads `boolean | ""`, and code that branches on it has to say what empty means instead of assuming the base type ([ADR 0029](../adr/0029-let-a-columns-empty-value-allowed-tick-decide-what-the-unmarked-value-read-means.md) keeps the blank in the column value type, since clearing a row writes one, and makes each read's name say what a blank means there). A Table can be met with only its header row, which a delete can leave live; with nowhere to put that, it would read as a Table with rows the run then writes outside ([ADR 0031](../adr/0031-keep-a-body-row-in-every-table-and-stop-a-run-on-a-header-only-table.md) gives a header-only Table its own stop, naming it with a one-line fix to add a row holding its formulas). A Table is stale once a flushed sort of it, or a flushed row delete on its sheet, may have moved its rows: its fetched indexes may no longer name the rows they did, so the flag lets a later use of its row indexes throw, naming the Table, instead of writing to the wrong row (sheets-framework#64). [ADR 0008](../adr/0008-check-table-placement-at-run-time-and-refuse-never-repair.md) gives a misplaced Table its own report, where it had been misreported as absent with advice to rebuild a working Table. [ADR 0024](../adr/0024-repair-a-payloads-omitted-rows-in-raws-finalize-pass-narrowed-to-the-table.md) gives a fetched-but-empty column blank facts, where it had been misreported as never fetched and crashed the config sync.
