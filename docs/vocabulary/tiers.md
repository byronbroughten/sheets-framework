# Tier words: Source, Platform, Raw, Identified, Named

The elaboration behind [docs/vocabulary.md](../vocabulary.md), whose one-line entries are the rules. These are the **architecture** words; the operator-facing ones live in [CONTEXT.md](../../CONTEXT.md).

If you're renaming or relocating something and aren't sure which word fits, ask rather than guess: these distinctions were deliberately hashed out, and folder placement depends on them.

- **Source** — the tier below everything that knows this spreadsheet: the `RawSource` port, the platform module (`GoogleSheets/`: the Google adapter and the Apps Script wrappers), and the cell values that cross the port.
- **Platform** — the spreadsheet product: Google Sheets now, Excel via Office Scripts later. It is a different axis from **host** (Apps Script or Node), so "platform-neutral" is not "host-neutral": platform-neutral code imports nothing from the platform module (`src/00_Source/GoogleSheets/`) and names no `GoogleAppsScript.*` type, and a lint rule holds that boundary.
- **Raw** — positional. It addresses a sheet by GID, a Table by its live `tableId`, and rows and columns by Table-relative index: `rowIndex` 0 is the first body row, column 0 the Table's first column, and the head rows above the header are reached by role at the offsets `tableLayout.headRowOffsets` declares. It is blind to column config: it resolves a column only from the Table's live head rows (the header row or the column-ID row), so a moved column resolves without regeneration. It reads the layout and the Table records (where each managed Table sits, which Tables a sheet holds) through `SpreadsheetBaseSchema` and `SpreadsheetSchema`, and a lint rule keeps column and value config out of its imports. Separating Raw from the Table records is open (sheets-framework#131). Sheet state keeps only per-sheet facts (title, `rowCount`, conditional formats, edit protections), and a `tableId`-keyed Table state holds the bounds, cells and queues. Raw's job is positional spreadsheet access only — fetching Table-bounded rows, columns and cells and sheet properties through `RawSource`. Sheet coordinates appear only when the flush gathers requests, converted against each Table's live bounds (sheets-framework#55, sheets-framework#62).
- **Identified** — adds the committed column config (value name, formula or data, default, how a blank reads, feedback columns), reached by column ID. It is typed by value name, not by Table or column name, so the framework's internal logic lives here without the type cost of Named's generics.
- **Named** — adds names: a Table by Table name, a column by header, and a sheet by its title, as a container. Values are typed per column, and the common case gets the unmarked accessor (`value`). It is the end developer's API.
- **`rowIndex`** — the body index: 0 is the Table's first body row, so it matches an array position in a body read, and the same number means the same row through Named, Raw and the write queue. A row counted from the sheet's top is a branded `SheetRowIndex` (a column, a `SheetColIndex`), used only in the source tier, at gathering, at the edit trigger's entry and in operator messages, which give the 1-based gutter number.
