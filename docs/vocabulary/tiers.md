# Tier words: Source, Platform, Raw, Identified, Named

The elaboration behind [docs/vocabulary.md](../vocabulary.md), whose one-line entries are the rules. These are the **architecture** words; the operator-facing ones live in [CONTEXT.md](../../CONTEXT.md).

If you're renaming or relocating something and aren't sure which word fits, ask rather than guess: these distinctions were deliberately hashed out, and folder placement depends on them.

- **Source** — the tier below everything that knows this spreadsheet: the `RawSource` port, the platform module (`GoogleSheets/`: the Google adapter and the Apps Script wrappers), and the cell values that cross the port.
- **Platform** — the spreadsheet product: Google Sheets now, Excel via Office Scripts later. It is a different axis from **host** (Apps Script or Node), so "platform-neutral" is not "host-neutral": platform-neutral code imports nothing from the platform module (`src/00_Source/GoogleSheets/`) and names no `GoogleAppsScript.*` type, and a lint rule holds that boundary.
- **Raw** — positional. It addresses a sheet by GID, a Table by its live `tableId`, and rows and columns by Table-relative index: `rowIndex` 0 is the first body row, column 0 the Table's first column, and the head rows above the header are reached by role at the offsets `tableLayout.headRowOffsets` declares. It knows the layout and sheet list through `SpreadsheetBaseSchema` and `SpreadsheetSchema`, and never resolves a column by name or `columnId`; a lint rule holds Raw files to that. Sheet state keeps only per-sheet facts (title, `rowCount`, conditional formats, edit protections), and a `tableId`-keyed Table state holds the bounds, cells and queues. Raw's job is positional spreadsheet access only — fetching Table-bounded rows, columns and cells and sheet properties through `RawSource`. Sheet coordinates appear only when the flush gathers requests, converted against each Table's live bounds (sheets-framework#55, sheets-framework#62).
- **Identified** — addresses a Table by its live `tableId` and a column by its column ID, knows each column's config (value name, default, blank coercion), and types values by the value-name union. A column's index isn't stored in config data; Identified resolves its Table-relative index live from the column's ID against the Table's column ID row, so a moved column resolves without regeneration.
- **Named** — config-dependent. It addresses a Table by Table name and a column by header, and a sheet only by its title, as a container.
- **`rowIndex`** — the body index: 0 is the Table's first body row, so it matches an array position in a body read, and the same number means the same row through Named, Raw and the write queue. A row counted from the sheet's top is a branded `SheetRowIndex` (a column, a `SheetColIndex`), used only in the source tier, at gathering, at the edit trigger's entry and in operator messages, which give the 1-based gutter number.
